Адвент на Railway

1. Создай отдельный приватный репозиторий GitHub, например advent-bot.
Загрузи файлы архива прямо в корень репозитория. Dockerfile и bot.py должны быть видны сразу при открытии репозитория.

2. В проекте Railway добавь новый сервис из этого репозитория.
Подключи к нему отдельный Volume с Mount Path /data.
Отключи Serverless, выбери Restart Policy Always.
Custom Start Command оставь пустым.
Пока ADVENT_BOT_TOKEN отсутствует, сервис ждёт настройки и остаётся доступным для переноса базы.

3. Сохрани открытый черновик адвента кнопкой «Сохранить» в Telegram.
Останови локальный адвент-бот через Ctrl+C в его окне Терминала.

4. В новом окне Терминала на Mac выполни по очереди:
source "$HOME/.railway/env"
cd "$HOME/Documents/advent-bot"
railway link

В railway link выбери проект и НОВЫЙ сервис адвента.
Проверь выбор:
railway status

Затем проверь диск:
railway volume files list /

Если advent.sqlite3 уже существует, сначала выясни, откуда взялась база, и сохрани её резервную копию перед заменой.

Если advent.sqlite3 отсутствует, загрузка выполняется через временное имя:
railway volume files upload ./advent.sqlite3 /advent.sqlite3.incoming
railway ssh -i "$HOME/.ssh/railway_ed25519" -- 'test ! -e /data/advent.sqlite3 && mv /data/advent.sqlite3.incoming /data/advent.sqlite3'
railway volume files list /

5. После успешного переноса в Variables НОВОГО сервиса добавь ADVENT_BOT_TOKEN.
Используй токен именно существующего адвент-бота. Фотографии сохранены как Telegram file_id и привязаны к этому боту.
Если его токен раньше раскрывался, отзови его через /revoke у BotFather и получи новый для того же бота.
Выбери Seal в меню переменной и примени изменения через Deploy.
Путь к базе /data/advent.sqlite3 определяется автоматически по Volume.

6. После запуска открой адвент-бота в Telegram.
Проверь меню, нажми «Отправить пробное сообщение», выбери 1 декабря и открой сюрприз.
Перезапусти сервис Railway и повтори проверку, чтобы убедиться, что база сохраняется.
Команда /invite выдаст персональную ссылку для получателя, если он ещё не подключён.
Локальная копия адвент-бота должна оставаться остановленной.

Сюрпризы и настройки продолжают редактироваться через Telegram.
Несохранённый черновик теряется при перезапуске.
Расписание — 1–24 декабря 2026, по умолчанию 08:00 Europe/Helsinki.
После простоя бот отправляет приглашение за текущий день, если время уже наступило.
За прошедшие дни автоматической рассылки нет.
